Features

Small app. Big reach.

One key, two superpowers. Everything else stays exactly where you left it.

✦

A real Hyper key

Hold Caps Lock and any key becomes ⌃⌥⇧⌘+key. A clean namespace for Raycast, Alfred and your own shortcuts that never collides with anything.

←

Home-row navigation

H J K L for arrows, ; and ' to jump words, I and O for line start and end, U and P to page. Hold Shift to select.

⌨

Every keyboard

Built-in, USB and Bluetooth keyboards all just work, including ones you plug in later. Nothing is seized, so media keys keep working.

⎋

Tap for Escape

Optional: a quick tap of Caps Lock sends Escape. Vim users, you are welcome.

⌘

Cheat sheet built in

Forgot a key? Open Key Mapping from the menu bar for a floating overview of the layer, with a switch for every optional key.

↺

Leaves no trace

Quit Hyperlayer and Caps Lock is back to normal on every keyboard. No kernel extensions, no drivers, no daemons.

How it works

Two layers, no hacks.

Hyperlayer uses the same system mechanisms as macOS itself, so it stays fast and out of the way.

01 / REMAP

Caps Lock becomes F18

The HID event system remaps Caps Lock on each keyboard, the same way hidutil does. New keyboards are picked up instantly and the mapping is restored if the system ever drops it.

⇪ Caps Lock→F18
02 / LAYER

One event tap does the rest

While F18 is held, layer keys are rewritten in place and every other key gets the four modifiers. One tap sees every keyboard, so there is nothing to re-inject.

F18+H→←·F18+T→⌃⌥⇧⌘T
Install

Ready in a minute.

  1. Download Hyperlayer.zip, unzip it and move Hyperlayer to Applications.
  2. Open it. The app is not notarized yet, so the first time macOS will refuse. Go to System Settings → Privacy & Security and click Open Anyway.
  3. Grant Accessibility when asked. Hyperlayer starts working the moment access is turned on.
  4. Hold Caps Lock and press H J K L. Turn on Launch at Login from the menu bar icon.
# or build from source
$ git clone https://github.com/royxue/hyperlayer
$ cd hyperlayer
$ make install
Needs Xcode Command Line Tools. Installs to /Applications and launches it.
